# Favorecidos finais de um documento de despesa

Favorecidos finais de um documento de despesa

## Usage

``` r
pt_favorecidos_finais(codigo_documento, max_paginas = Inf)
```

## Arguments

- codigo_documento:

  Código completo (UG + gestão + número), como em `codigo_documento` de
  [`pt_emenda_documentos()`](https://strategicprojects.github.io/siop/reference/pt_emenda_documentos.md).

- max_paginas:

  Limite de páginas (15 registros cada). Padrão: todas.
