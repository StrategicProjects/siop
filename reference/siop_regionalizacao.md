# Regionalização das ações do Orçamento Federal

Regionalização das ações do Orçamento Federal

## Usage

``` r
siop_regionalizacao(exercicio, refresh = FALSE)
```

## Arguments

- exercicio:

  Ano.

- refresh:

  Baixar novamente ignorando o cache.

## Value

Tibble; colunas `Liquidado*`/`Realizado*` numéricas.
