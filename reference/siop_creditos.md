# Alterações orçamentárias (créditos) de um exercício

Alterações orçamentárias (créditos) de um exercício

## Usage

``` r
siop_creditos(exercicio, refresh = FALSE)
```

## Arguments

- exercicio:

  Ano.

- refresh:

  Baixar novamente ignorando o cache.

## Value

Tibble; `val_acrescimo` e `val_reducao` numéricos.
