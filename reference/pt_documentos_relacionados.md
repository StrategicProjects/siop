# Documentos relacionados a um documento de despesa

Documentos relacionados a um documento de despesa

## Usage

``` r
pt_documentos_relacionados(codigo_documento, fase)
```

## Arguments

- codigo_documento:

  Código completo (UG + gestão + número), como em `codigo_documento` de
  [`pt_emenda_documentos()`](https://strategicprojects.github.io/siop/reference/pt_emenda_documentos.md).

- fase:

  1 = empenho, 2 = liquidação, 3 = pagamento.
